# Video-Edit-Ai

영상 미리보기, 자막 편집, 타임라인 편집 기능을 중심으로 구현하고 있으며, 최종적으로는 음성 인식 결과를 이용해 텍스트 기반으로 영상 구간을 편집하는 기능을 목표로 합니다.

## 주요 기능
- 영상 미리보기 및 재생 제어
- 자막 목록 조회 및 텍스트 수정
- 자막과 영상 재생 시간 동기화
- 영상·오디오·자막 트랙 표시
- 타임라인 클립 선택 및 위치 표시
- 프로젝트 편집 상태 관리

## 기술 스택
- React
- TypeScript
- Vite
- React Compiler
- CSS Modules
- Context API

## 실행 방법
```bash
npm install
npm run dev
```
