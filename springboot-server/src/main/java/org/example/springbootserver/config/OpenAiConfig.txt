어노테이션 : @로 시작하는 문법. 코드에 추가적인 의미/정보를 붙이는 표시
@BEAN : 이 메서드의 return값을 Spring Container에 등록하라는 어노테이션. 생성자 없이 Spring이 자동을 메서드 호출함.
Spring Container는 Spring이 객체들을 만들어서 보관하고 관리하는 공간.Bean은 spring이 관리하는 객체


@Bean   // 이 메서드가 반환하는 객체를 스프링이 관리해줘
@Value  // application.properties 등의 설정값을 가져와줘

@Bean은 보통 @Configuration 클래스안에서 사용됨.

"${openai.api-key}"  ${}는 Spring에서 설정값을 조회하겠다는 문법

@Configuration : Spring 설정 클래스임을 표시

@Override는 부모 클래스나 인터페이스에 이미 정의된 메서드를 내가 다시 구현한다는 표시
